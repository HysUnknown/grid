## 1. 简介

**网格**（英文代号 **Grid**，"网"为拦截之网）是一套三端广告拦截工具，本仓库当前交付 **Android 版**：

- **Android App**（Kotlin，无障碍服务）：开屏自动跳过、弹窗自动关闭、阻止跳转其他 App、营销弹窗自动关闭，并支持**自定义规则录制与分享**。
- **APK 不内置任何规则库**：规则全部来自用户本地——自行录制，或导入他人分享的规则集文件（GKD 订阅格式）。零网络、零内置，规则由用户自管理与分发。
- 引擎为**自研简化版 GKD 兼容引擎**，只实现选择器常用子集（不 fork GPL 代码、不 100% 复刻）。

工程形态（`android/`）：

| 模块 | 包名 | 说明 |
|---|---|---|
| `:engine` | `cn.hys159x.grid.engine` | 纯 Kotlin JVM 引擎，零 Android 依赖，65 个单元测试 |
| `:app` | `cn.hys159x.grid.app` | Android 宿主：无障碍服务、规则加载（本地）、Compose UI、Room 日志 |

- 选择器子集对 GKD 官方订阅 v186 的覆盖率为 **98.7%**（1973 条规则中可编译 1947 条），详见[第 7 节](#7-规则兼容)。
- **iOS 版**（NEPacketTunnelProvider DNS 过滤，iOS 沙箱不允许第三方全局自动点击）与 **HarmonyOS NEXT 版**（ArkTS AccessibilityExtensionAbility）的完整设计见 [`docs/specs/2026-09-20-ad-blocker-design.md`](docs/specs/2026-09-20-ad-blocker-design.md)。

## 2. 下载安装

系统要求：Android 8.0+（minSdk 26）。

1. **下载 APK**：从本仓库的 GitHub Releases 页面下载最新版 APK。当前版本 0.1.0 尚未发布首个 Release（发版前须完成签名配置，见[第 6 节](#6-构建)），在此之前可按第 6 节自行构建 debug 包体验。
2. **安装**：在系统提示时允许"未知来源 / 安装未知应用"权限，完成安装。
3. **开启无障碍**：设置 → 无障碍 → 已下载的应用 → 网格 → 开启。开启后首页显示"服务运行中"。
4. **保活设置（华为 / 小米等机型必做）**：允许自启动、关闭电池优化、在最近任务中锁定后台，防止无障碍服务被系统回收。服务意外断连时应用会发送通知提醒重新开启。
5. **总开关**：首页开关关闭后，事件入口即刻短路，拦截完全停止，无需关闭无障碍权限。

## 3. 自定义规则

规则覆盖不到的 App（或新版 App 广告样式变了），可以在应用内自己录一条规则，全程无需了解选择器语法：

### 录制

1. 首页 → 自定义规则 → 在应用列表找到目标 App，点「录制」；
2. 应用自动打开，服务在开屏页上**自动扫描**「跳过 / 关闭」按钮（只收可点击节点，杂音文案自动排除，"跳过"类按钮排最前）；
3. 回到自定义规则页，顶部出现候选列表，点「添加」即生效；不想要的候选可删除或编辑后再添加。

命中自定义规则的按钮会进入**循环点击**（每 200ms 重查节点点击，直到按钮消失，8 秒超时），倒计时没走完也照点不误。

### 返回键规则（应对点击反制）

部分 App（如大麦）会检测无障碍来源的点击并忽略——点击路径对它完全无效。对这类 App，编辑规则把动作改为**按返回键**：检测到广告页节点即按返回，直接关闭整个开屏页，绕过一切点击反制。

### 导入 / 导出

规则的流转有轻量文本与大文件两条通道，按需选用：

**导出**（自定义规则页 → 导出，二选一）：

- **以文本分享**：仅你自己录制的自定义规则打包成一段文本，经系统分享面板直接发微信等任意渠道——对方复制后粘贴导入即可；
- **生成文件分享**：当前全部生效规则（自定义 + 已导入的外部规则集）打包成一个 GKD 订阅格式的 `.json` 文件发送。

**导入**（自定义规则页 → 导入，二选一）：

- **粘贴文本**：复制别人分享的规则文本 → 「粘贴」→「导入」，按 `包名 + 选择器` **去重合并**——已有规则原样保留，只追加本地没有的；
- **从文件导入完整规则集**：选择收到的 `.json` 规则集文件（先校验能完整编译，坏文件拒绝落盘），作为**外部规则集**生效并在规则页标注，可随时移除。

### 优先级

自定义规则**优先于外部导入的规则集**评估（相同目标节点时你的规则先命中），动作类型（点击 / 返回键）也以你的为准。

## 4. 工作原理

```
启动 → 加载本地规则（自定义规则 + 外部导入的规则集文件，若有）
     → 解析 → 编译为 CompiledRuleSet（自定义规则永远排最前）
     → 无障碍事件到达 → 快照匹配选择器 → 命中即执行动作（点击 / 循环点击 / 返回）
     → 写入本地拦截日志（Room）
```

本地引擎四大组件 + 宿主模块结构：

```
android/（Gradle 双模块）
├── engine/                 纯 Kotlin JVM 引擎（零 Android 依赖，可独立单测）
│   ├── selector/           选择器解析：GKD 语法子集 → AST（依据 selector-spec.md）
│   ├── match/              节点匹配：属性求值 + 链关系（>/</<</+/-）验证
│   ├── rule/               规则执行：快照匹配、动作触发、节流预算
│   ├── subscription/       订阅编译：GKD JSON5 → RawSubscription → CompiledRuleSet
│   └── node/               TreeNode 平台无关节点接口（贯穿以上四组件的解耦点）
└── app/                    Android 宿主（包名 cn.hys159x.grid.app）
    ├── service/            无障碍服务：事件驱动匹配、A11yNode 适配、连点与返回键动作
    ├── subscription/       规则仓库：自定义规则 + 外部导入规则集（全本地，零网络）
    ├── ui/                 Compose 界面：总开关 / 权限引导 / 拦截日志 / 自定义规则
    └── data/               Room 拦截日志（本地库，保留最近 200 条）
```

### 性能与体验治理

- **事件风暴静默**：App 冷启动窗口（20s）过后 `CONTENT_CHANGED` 事件全跳，启动窗口内 400ms 节流，单轮匹配 200ms 硬预算；
- **规则查询按包名缓存**：高频无障碍事件回调 O(1) 取规则，不与 UI 线程争抢主线程时间；
- **用户触摸让路**：手指在屏期间暂停一切合成点击手势，避免自动点击打断你的滑动；
- **全局点击去抖**：同一位置 800ms 内只点一次，防止系统把连续点击合并成双击。

### 关于规则来源（如实说明）

APK **不打包任何规则文件**，运行时也不联网拉取。当前生效的规则只有两个来源，全部由用户自管理：

1. **自定义规则**（第 3 节录制 / 手动编辑）；
2. **外部导入的规则集文件**（GKD 订阅格式，他人分享或自行制作，导入后可随时移除）。

需要一份「开箱即用」的规则底座时，可从 GKD 社区订阅（[github.com/gkd-kit/subscription](https://github.com/gkd-kit/subscription)，已停止维护，v186 为最终版）或任何 GKD 兼容订阅源获取规则文件，经「导入 → 从文件导入完整规则集」加载。规则随各 App 版本迭代可能失效，这正是自定义规则功能存在的意义。

## 5. 隐私声明

本节为分发合规声明，逐条如实说明应用的数据行为：

1. **完全离线，无联网权限。** 应用不申请 `INTERNET` 权限——不存在任何网络请求，无账号体系，无统计 / 埋点 / 崩溃收集 SDK，无广告 SDK；不申请通讯录、位置、存储、电话等任何个人信息权限。应用申请的全部权限仅 2 项：
   - `POST_NOTIFICATIONS`——无障碍服务断连时的本地提醒通知；
   - 无障碍服务（系统绑定权限）——在本地执行广告节点匹配与点击。
2. **规则不内置、不联网。** APK 不打包任何规则文件，运行时不存在网络请求；规则全部来自用户本地的自定义录制与手动导入，数据完全在用户自己掌控之下。
3. **不上传任何内容。** 应用不存在任何数据上传代码路径。无障碍服务读到的**节点树数据仅在内存中完成选择器匹配后即丢弃**：不写入磁盘、不缓存、不经过网络发送。屏幕内容不会被截图、录制或导出。
4. **日志仅存本地。** 拦截记录（时间、包名、动作、节点描述）只写入应用私有 Room 数据库（`grid.db`，保留最近 200 条），不导出、不上传；卸载应用即随私有数据一并彻底清除。
5. **不参与系统云备份。** `android:allowBackup="false"`，应用数据不会被系统备份到云端。

## 6. 构建

环境要求：JDK 17，Android SDK（compileSdk 35）。

```bash
# Windows
cd android && ./gradlew.bat :app:assembleDebug

# macOS / Linux（CI 同）
cd android && ./gradlew :app:assembleDebug
```

产物：`android/app/build/outputs/apk/debug/app-debug.apk`。

引擎单测（纯 JVM，无需设备 / 模拟器；官方订阅回归 fixture 已入库，可直接运行）：

```bash
cd android && ./gradlew :engine:test
```

**Release 构建与签名：** `buildTypes.release` 已接入签名配置，密钥信息从不入库的 `android/keystore.properties` 读取（`*.jks` 与 `keystore.properties` 均在 `.gitignore` 中）。克隆者自行发版需：

1. 自备 keystore，写入 `android/keystore.properties`（`storeFile` / `storePassword` / `keyAlias` / `keyPassword`）；
2. 执行 `./gradlew :app:assembleRelease` 产出正式签名包（无该文件时自动退化为无签名包）；
3. 经 GitHub Releases 发布并附 sha256 校验值。

**CI：** push 到 `main` 或提交 PR 时，GitHub Actions 自动运行引擎测试并构建 debug APK 工件（见 [`.github/workflows/android.yml`](.github/workflows/android.yml)）。

## 7. 规则兼容

- 支持的选择器语法子集以 [`docs/specs/selector-spec.md`](docs/specs/selector-spec.md) 为唯一依据，要点：
  - 目标节点：`@` 标记的属性选择器，无 `@` 时取最后一个；
  - 关系符：空格（祖先）、`>n`（第 n 层祖先）、`<n`（第 n 层子）、`<<n`（子孙）、`+n` / `-n`（前后兄弟），均支持多值形式 `>(a1,a2)`；
  - 属性：`id/vid/name/text/desc`、布尔状态（`clickable` 等）、几何（`left/top/...`）、结构（`childCount/index/depth`）与 `text.length/desc.length`。
- **不支持语法自动跳过**，不报错、不中断，并在引擎测试覆盖率报告中体现：`OfficialSubscriptionRegressTest` 以官方订阅 v186 全文为回归 fixture（**不入库**，避免随仓库分发大体积规则文件；从 classpath、`GRID_FIXTURE` 环境变量或仓库外 `rules-fixture/` 目录查找，缺失时自动跳过），断言总规则数 > 1000 且不支持语法占比 < 5%，并逐条打印 skip 明细用于定位高频缺口。
- 实测覆盖率：v186 共 **1973** 条规则，引擎成功编译 **1947** 条，覆盖率 **98.7%**。
- 语义判定以 selector-spec §7 标准用例集为准；未来 TS 引擎（HarmonyOS）与 Kotlin 引擎须在该用例集上结果一致。
