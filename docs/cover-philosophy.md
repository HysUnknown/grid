# Voltage Noir（电压黑）

## 设计哲学

黑暗不是背景，是媒介本身。这个哲学相信：真正的高信号，只在绝对的黑暗中显形。夜晚的城市不需要花哨——出租车顶灯、地铁警示条、跑道边灯，全部是黑与一种黄构成的二色世界，而正是这种极端的克制，让每一个黄都在尖叫。作品必须像深夜里唯一亮着的那块屏：观者无法移开视线。

形式上，这个运动崇尚**单色电压**。画面中只允许存在一个主色，且这个色必须携带能量——不是柔和的点缀，而是电流般的注入。黑色的领域越深、越纯，黄色的电压就越高。灰阶只以极小的剂量出现，作为刻度、作为呼吸、作为精密仪器上的读数，绝不让它稀释主色的统治力。每一处留黑都是蓄能，每一笔黄色都是放电。

节奏来自**倒计时的呼吸**。这个哲学从时间压力中借来它的韵律：数字在递减，透明度在衰减，序列在消失——观者即使不知道叙事，也能感到"某件事正在被终结"。衰减序列必须精心校准：步长均匀、间距如乐谱、余韵干净。这是时间的可视化，也是整件作品的心跳。

构图奉行**右上角的仪式**。屏幕时代的所有人都认识那个位置——右上角那个小小的、带边框的、写着倒计时的胶囊。它是整个时代最普遍的图形符号之一。将它抽离、放大、供奉在构图的神圣角落，用最精确的圆角、最克制的描边、最考究的内边距去重绘它。内行会在看见的一瞬微笑，外行只会觉得：这个符号长得真讲究。

最终呈现必须像一件**被反复打磨过的信号仪器**：裁切标记如印刷厂的十字线，等宽小字如实验记录，警戒斜纹如工业安全规范。所有元素对齐到看不见的网格，间距经过毫厘级推敲。这不是海报，是一件证明"注意力的争夺也可以被工艺化"的证据。看它的人应该感到：这背后是一百个小时的偏执。

## 概念暗线（不外显）

开屏广告右上角的「跳过 N」按钮与它的倒计时——被抽象为胶囊描边、递减数字序列与警戒斜纹。懂的人自会心一笑。
