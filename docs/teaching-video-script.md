# 网格（Grid）教学视频脚本（一分钟版）

> 成片时长目标：约 60 秒。竖屏，快节奏剪辑，每个镜头只讲一件事。
> 演示道具：`ademo` 广告演示 App（仓库 `android/ademo` 模块，5 秒倒计时跳过，无频控可重拍）。
> 旁白为建议文案，语速自然偏快；「画面」列括号为拍摄提示。

## 注意事项

1. 全片节奏靠快切，单镜头别超过 8 秒。
2. 开飞行模式拍分镜 2——「离线也能用」是最强卖点，角标点明。
3. 广告演示 App 无频控可无限重拍；真实 App 有频控，不作主演示。
4. 简介区附：GitHub 链接、无障碍权限用途说明、免责声明全文。
